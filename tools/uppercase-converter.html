Common questions

Does it handle accented letters?

Yes — it uses the browser's built-in uppercase conversion, which correctly handles accented Latin characters (é → É) and most non-English alphabets.

Will this affect numbers or punctuation?

No — only letters change case. Numbers, spaces and punctuation pass through unchanged.

Can I use this instead of CSS text-transform?

For display purposes, CSS `text-transform: uppercase` is usually better since it doesn't change the underlying text. Use this converter when you need the actual characters changed — for a title, a filename, or copy you're pasting elsewhere.
