Common questions

Does X count links and mentions differently?

Yes — X shortens URLs to a fixed length (currently 23 characters) regardless of the real link length, and this counter can't know that, so a post full of links may show as "over" here while actually fitting on X. Treat plain text counts as exact and link-heavy posts as an estimate.

Do emoji count as one character on X?

Most single emoji count as 2 characters on X's own counter (it counts in UTF-16 code units), which can differ from this tool's count for emoji-heavy text — for plain text they'll match.

Is 280 the limit for everyone?

280 is the standard limit for most accounts. Some subscription tiers get a much higher limit, in which case this specific page isn't the right target — use the plain character counter instead and track your own limit.
