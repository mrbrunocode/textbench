Common questions

Why SHA-256 instead of MD5?

SHA-256 is cryptographically strong and still considered secure for integrity checks and many security use cases, unlike MD5 or SHA-1, both of which have known collision weaknesses.

How is this computed — is it really running locally?

Yes — it uses the Web Crypto API (crypto.subtle.digest) built into your browser, the same engine used by real cryptographic applications, entirely on your device.

Is this suitable for hashing passwords?

Not on its own — a raw SHA-256 hash of a password is vulnerable to precomputed lookup-table attacks. Real password storage needs a slow, salted algorithm designed for that purpose (bcrypt, Argon2, scrypt), not a fast general-purpose hash like this.
