Common questions

Is the sort case-sensitive?

No — it sorts case-insensitively ("apple" and "Apple" sort the same way), which matches how most people expect an alphabetical list to behave.

How are numbers sorted?

Numbers sort as text by default, so "10" comes before "2" (because "1" < "2" as characters). For numeric sorting, pad numbers with leading zeros first, or sort in a spreadsheet instead.

What happens to blank lines?

Blank lines sort to wherever an empty string would fall — typically first — so you may want to remove empty lines before sorting if that's not what you want.
