Common questions

Why would I need this?

Common cases: someone pastes text with Caps Lock stuck on, you're normalizing data for a spreadsheet, or you need lowercase input for a slug or username field.

Does it change accented characters correctly?

Yes, it uses standard lowercase conversion which handles accented and most non-English letters correctly.

Is this the same as a case-insensitive search?

No — this actually rewrites the text. A case-insensitive search compares text without changing it. Lowercasing both sides is one way to implement that comparison yourself.
