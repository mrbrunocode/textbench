Common questions

What format are the numbers in?

Each line is prefixed with "1. ", "2. ", and so on. If you need a different format (like "[1]" or just "1"), do a quick find-and-replace on the result.

Does numbering restart for blank lines?

No — blank lines get a number too, counted the same as any other line, so the numbering stays continuous and matches what you'd see in a code editor's gutter.

Can I remove the numbers later?

Yes — paste the numbered text into the "remove line breaks" or a find-and-replace tool with a pattern like "^\d+\. " if you need to strip them back out.
