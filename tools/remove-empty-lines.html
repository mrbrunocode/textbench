Common questions

What counts as an "empty" line?

A line that's completely blank, or contains only spaces/tabs, is removed. A line with any visible character stays.

Will this affect paragraph spacing I want to keep?

Yes — this removes every blank line, including ones you're using as paragraph breaks. If you only want to collapse multiple consecutive blank lines down to one, do that manually, since this tool removes them all.

Does the line order change?

No — the remaining lines stay in their original order, just with the blank ones removed.
