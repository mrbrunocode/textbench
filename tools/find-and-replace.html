Common questions

Is the search case-sensitive?

Yes, by default. There's no separate case-insensitive toggle yet — for a case-insensitive replace, run it twice with different capitalizations of your search term, or use a regex like "(?i)word" isn't supported, so instead try a character-class pattern in regex mode.

What does regex mode add?

With regex mode on, the "find" field is treated as a JavaScript regular expression (e.g. \d+ for any number) instead of a literal string, so you can match patterns rather than exact text. All matches are replaced (equivalent to the /g flag).

What happens if my regex is invalid?

If the pattern doesn't parse, the text is left unchanged rather than throwing an error onscreen — check your pattern for unescaped special characters if the replace doesn't seem to do anything.
