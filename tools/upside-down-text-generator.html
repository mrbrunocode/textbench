Common questions

Does every character have an upside-down equivalent?

Most common letters and numbers do, using look-alike Unicode characters from various scripts. A few uncommon symbols don't have a good match and are left as-is.

Is this real text or an image?

Real Unicode text — it copies and pastes like normal text anywhere, including social media bios, usernames and chat apps.

Why is the string reversed too?

Flipping each character upside down without reversing the order would put the last letter first when read normally — reversing the order as well makes the whole word read correctly when the page (or your head) is turned upside down.
